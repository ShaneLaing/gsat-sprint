學生說這題不會：$ARGUMENTS

1. 依 `docs/INDEX-SPEC.md` 的編號規則判斷是哪一份索引（`index/textbook/`、`index/mock/`、`index/gsat/`），找到那一列。題號不清楚就用一句話跟他確認。
2. 用 Read 讀對應 PDF 的那一頁（`pages` 參數），看清楚題目。
3. 用對話方塊問他目前的狀況，選項：「完全沒頭緒」「寫了一半卡住」「有答案但不確定」。選後兩項時，請他打出寫到哪裡或他的答案。
4. 照 `CLAUDE.md` 的「教法：引導式提問」帶他走「觀察 → 線索 → 嘗試解法」，**不要直接給解法，也不要逐步追問運算**；策略對了就讓他自己算，只對關鍵結果。索引裡的「觀念ID」「該抓的線索」只給你自己備課用。解完後，有值得的另解就照「一題多解」問他要不要挑戰。
5. 他得出答案後，才可打開 `index/answers/` 或詳解 PDF 對答案。
6. 結束時：
   - 你先判斷**故障類型**（六種之一，見 `CLAUDE.md`），用一句話告訴他歸在哪類、為什麼，再用對話方塊問「這樣歸類對嗎？」（選項「對」「不太對」）；他選不太對，就用對話方塊列出 2–3 個可能的類型讓他選。寫進 `state/mistakes.md`，狀態「待複習」。
   - 碰到的觀念寫進／更新 `state/concepts.md`。
   - 問他「下次看到什麼會想到這招？」，寫進 `state/signals.md`。**他說要停的時候也要先問這一句**（一句話就好）；他不想答，才在 `state/progress.md` 的「下次從這裡開始」註明下次開頭補問。
   - 若這題用到兩章以上的東西，寫進 `state/bridges.md`。
   - 若這是對話式的題，把它從 `state/progress.md` 的「跳過的題」移除（若在清單上）。
7. 用 2–3 句話告訴他記了什麼，再用對話方塊問接下來要做什麼：「下一題」「回選單」「今天先到這」（選最後一項就照 `/wrap` 收尾）。
