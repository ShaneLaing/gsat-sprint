# 學測數學A 衝刺包

這是一個給 Claude Code 用的讀書資料夾。打開它之後，Claude 會變成你的數學家教：你說哪一題不會，它會打開那一頁，一步一步問你問題帶你做出來，並幫你記下不會的觀念，之後再抽考你。

## 安裝（第一次）

1. 安裝 Claude 桌面版（https://claude.com/download），登入後切到 **Code** 分頁。
   （也可以用終端機版 Claude Code。）
2. 家教老師會把這個資料夾放到你的電腦上。
3. 在 Claude Code 選擇這個資料夾開啟。

## 怎麼用

**每次打開後，在下面的輸入框打「開始」按 Enter。** Claude 會跳出選單，你用滑鼠點選就好，不用記任何指令。

- 選單出現時，點你要的選項；選項都不合適，就點「其他」直接打字。
- Claude 請你「直接打字回答」的時候（例如用自己的話解釋觀念），就在輸入框打字。
- 也可以直接說你要做什麼，例如「第三章類題 12 不會」「我要寫 114 E3」「我現在哪些觀念最弱？」

會用指令的話，也可以直接打（完整說明見 [command_list.md](command_list.md)）：

| 指令 | 用途 |
|---|---|
| `/chapter ch03` | 盤點這一章跳過哪些題，一題一題補 |
| `/stuck 114-E3-07` | 這題不會 |
| `/exam 114-E3` | 寫一份模考或學測 |
| `/quiz` | 抽考 3 個觀念＋3 題 |
| `/status` | 看自己的觀念狀態和進度 |
| `/wrap` | 今天結束，整理紀錄 |

## 題號怎麼寫

| 對象 | 寫法 | 例 |
|---|---|---|
| 對話式觀念 | `chNN-KMM` | `ch03-K10`＝第 3 章觀念⑩ |
| 對話式例題 | 觀念編號＋字母 | `ch03-K10A`＝觀念⑩的例A |
| 對話式其他題 | 直接說書上的標籤 | 「第三章類題 12」「第三章綜測 5」 |
| 模考 | `年-卷-題號` | `114-E3-07`＝114 年 E3 模考第 7 題 |
| 學測 | `年A-題號` | `115A-07`、`115A-13`（選填也是數字題號） |

記不得也沒關係，用說的 Claude 會幫你對。只說頁碼的話要加章號（第 3–4 冊的頁碼從 1 重新算）。

## 資料夾裡有什麼

| 資料夾 | 內容 |
|---|---|
| `pdf/` | 對話式課本、模考（含詳解）、學測歷屆的原始 PDF |
| `index/` | 每一題、每個觀念在哪一頁的索引（Claude 用來找題目） |
| `index/answers/` | 答案（Claude 只會在你寫完之後才打開） |
| `state/` | 你的錯題、觀念強度、抽考紀錄 |
| `docs/plan.md` | 70 天規劃 |

## 給家教老師

- 這個 repo 含有版權教材（對話式課本、模考題本），**請保持 Private**。
- 學生不用 GitHub：由老師在 GitHub 頁面按 **Code → Download ZIP**（或直接複製資料夾）放到學生電腦。
- 學習紀錄只存在學生電腦的 `state/` 資料夾。上課時打開那個資料夾，或請學生在 Claude 點「看我的進度」即可查看。
- **之後要更新這個包時，不要覆蓋學生電腦上的 `state/` 資料夾**，否則紀錄會被清空；只替換其他檔案。
- 學生端的 Claude Code 帳號設定見 [docs/setup.md](docs/setup.md)。
- 學測歷屆第 1–18 題答案已逐題對過大考中心官方答案；第 19–20 題非選擇題為 Claude 自解（標記 `Claude解-待核對`），可對照大考中心的「非選擇題參考答案與評分原則」。
- 索引只記頁碼、標籤與自己寫的摘要，沒有抄錄教材原文；題目內容一律以 PDF 為準。
