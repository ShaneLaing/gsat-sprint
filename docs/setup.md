# 學生端 Claude 帳號設定（給家教老師）

這個資料夾是**自帶設定**的：用 Claude Code 打開它，家教規則和指令就會自動載入。新帳號幾乎不需要額外設定。

## 需要的

| 項目 | 設定 |
|---|---|
| 訂閱方案 | 含 Claude Code 的方案（Pro 以上） |
| 軟體 | Claude 桌面版（https://claude.com/download），使用 **Code** 分頁 |
| 資料夾 | 在 GitHub 頁面按 **Code → Download ZIP**，解壓縮到學生電腦（例如「文件」底下），不需要安裝 git |
| 第一次開啟 | 在 Code 分頁選擇這個資料夾。出現「是否信任這個資料夾」時按**信任**——不信任的話，下面的權限設定不會生效，Claude 每次寫紀錄都會跳出確認 |

> 不要用 claude.ai 一般聊天的「Projects」功能：它不能讀整個資料夾的 PDF，也不支援這裡的指令和紀錄檔。

## 不需要的

| 項目 | 說明 |
|---|---|
| Skills | 不需要。讀 PDF、對話方塊（AskUserQuestion）都是 Claude Code 內建功能。 |
| MCP / 外掛（plugins） | 不需要。所有資料都在資料夾裡。 |
| System prompt | 不需要另外設定。資料夾裡的 `CLAUDE.md` 就是家教規則，開啟時自動載入；`.claude/commands/` 的指令也會自動出現。 |
| 權限設定 | 已附在 `.claude/settings.json`：只允許 Claude 不經確認就修改 `state/` 裡的學習紀錄，其他檔案仍會先問。 |
| GitHub / git | 不需要。學習紀錄只存在學生電腦的 `state/` 資料夾。 |

## 建議

- **權限模式**：用預設模式即可，不要開「略過所有權限確認」之類的模式。
- **模型**：用桌面版預設的模型就好；需要更穩的解題品質時可在模型選單選最高階的模型。
- **帳號的全域設定**：不要在帳號層級另外加教學相關的指示或輸出風格，以免和 `CLAUDE.md` 衝突。
- **第一次測試**：開啟資料夾後打「開始」，應該會跳出「今天要做什麼？」的選單。有跳出就代表設定成功。

## 之後更新這個包

下載新版後，**只替換 `state/` 以外的檔案**。`state/` 是學生的錯題、觀念和進度紀錄，覆蓋掉就會清空。
